# SEO Checklist por Página - Jota R Marketing

Objetivo: manter o mesmo padrão de ajuste em todas as páginas, com foco em SEO técnico, SEO local e conversão.

Como usar:
- Marque [x] quando concluir o item.
- Sempre execute na ordem: Crítico -> Alta -> Média -> Conteúdo contínuo.
- Repita o mesmo bloco para cada página.

## 1) Padrão único por página (usar em todas)

### Crítico
- [ ] Garantir 1 único H1 por página com palavra-chave principal + geolocalização.
- [ ] Corrigir hierarquia semântica: H1 -> H2 -> H3 (sem pular níveis).
- [x] Remover meta keywords, caso exista.
- [x] Navegação principal com links <a href="#secao"> (evitar <button> para navegação).
- [ ] Inserir NAP no rodapé:
  - Nome: Jota R Marketing
  - Endereço: Praia Grande (atende Brasil e Mundo)
  - Telefone: +55 13 98994-965
- [ ] Garantir canonical, title e meta description próprios da página.

### Alta (conversão e UX)
- [ ] CTA primário acima da dobra (primeiro viewport).
- [ ] CTA secundário após cada seção de serviço.
- [x] CTA final de urgência no rodapé.
- [x] Trocar textos fracos por verbos com benefício:
  - "Saiba mais" -> "Quero um site que vende"
  - "Contato" -> "Solicitar análise gratuita agora"
  - "Enviar" -> "Receber proposta pelo WhatsApp"
- [ ] Adicionar breadcrumbs visíveis e navegáveis.

### Média (estrutura e performance)
- [ ] Revisar FCP (alvo < 1s): fonte com preload/preconnect e CSS crítico inline quando aplicável.
- [ ] FAQ por página com schema FAQPage (JSON-LD).
- [ ] Verificar links internos entre páginas locais e home.

### Conteúdo contínuo
- [ ] Manter calendário de blog: 1 a 2 posts/mês.
- [ ] Criar guias completos, comparativos e checklists gratuitos (lead magnet).
- [ ] Revisar trimestralmente title/description conforme termos que mais convertem.

## 4) Critério de pronto (DoD)

Uma página só é considerada pronta quando:
- [ ] Tem 1 H1 único com keyword + geolocalização.
- [ ] Possui title/description/canonical corretos.
- [ ] Tem CTA primário acima da dobra, secundários por seção e CTA final no rodapé.
- [ ] Possui NAP no rodapé.
- [ ] Tem breadcrumbs visíveis.
- [ ] Possui schema válido (FAQ quando aplicável).
- [ ] Passa em validação de performance e indexação básica.
